Install App on iPhone/iPad

Install Moin's Cafe on your iPhone or iPad in a few taps (no App Store needed):

  1. Open this site in Safari.
  2. Tap the Share icon (square with an arrow up).
  3. Scroll down and tap Add to Home Screen.
  4. Tap Add. The app will appear on your home screen.
Tip: After installing, open it from your home screen. All admin features, menu updates, and ordering tools will work in the app.

Instant Sync (All Devices)

Recommended: Firebase Realtime Database (instant updates)

Connect once, then any menu/photo/price change made from any gadget updates for everyone in real time. For this to work on all visitors' devices, the same Firebase config must be embedded in the moins-cafe.html file you upload to your hosting.

Quick setup:
  1. Create a Firebase project and add a Web App.
  2. Create a Realtime Database and set rules to allow read/write (or secure as needed), e.g. {"rules":{".read":true,".write":true}} for quick testing.
  3. Copy the Firebase config JSON and paste it above, then click Connect & Enable Instant Sync.
  4. Click Copy Embed Code for HTML, open moins-cafe.html, replace const EMBEDDED_FIREBASE_CONFIG = null; with the copied line, save and upload that updated HTML to your hosting.
  5. After that, everyone loads the same configured file and all changes sync instantly across gadgets.

Note: uploaded device photos are stored as base64 data in the database and can become large/slow. Prefer image URLs when possible.

Backup / Manual publish (if not using Firebase)

Without Firebase, you must upload moins-cafe-data.json next to moins-cafe.html after each change for other devices to see updates.
